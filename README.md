# Typeform Flow Demo

A polished, single-screen-per-question form experience built with Next.js, Framer Motion, and local state persistence.

## What it includes

- One question per screen
- Branching flow based on the first answer
- Keyboard support for Enter, Shift+Enter, and Escape
- Validation before advancing
- Local persistence with `localStorage`
- Vertical slide transitions and staggered entrance animation

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Let Vercel use the default Next.js settings.
4. Deploy.

## Notes

- The flow is designed to be dropped into a standard Next.js app.
- The project is intentionally minimal and easy to maintain through GitHub.
